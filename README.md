# Canonical Pitch Deck: Hybrid Cloud Migration Proposal

This repository contains an interactive, slide-based strategic proposal designed for **NetEase Youdao (NYSE: DAO)** to optimize their large-scale APAC EdTech infrastructure (54,640 vCPUs) by migrating core video transcoding workloads from AWS public cloud to a Canonical-managed Charmed OpenStack private cloud.

## 📊 Project Overview

- **Target Workload:** 54,640 vCPU peak load (Video Transcoding, Media/WebRTC, Core Database, API, and AI Inference).
- **Core Strategy:** A Hybrid Cloud architecture shifting **88%** of baseline workloads to Charmed OpenStack (private cloud) while retaining **12%** on AWS for elastic burst scaling.
- **Estimated Savings:** Over **$21.4M USD** saved in 3-Year TCO compared to 100% public cloud.
- **Regulatory Readiness:** Tailored architecture to meet APAC data residency laws, including Mainland China's **PIPL**, Singapore's **PDPA**, and Hong Kong's **PDPO**.
